# Happy Plant - трекер полива растений

Вебсайт, который определяет растения по фото, отслеживает время их полива. 

# Как работает

|   Пользователь загружает фото     |
|               |                   |
|               V                   |
|   Обращение к Plant.id API за     |
|   инфомацией о виде растения      |
|   и рекомендациями по поливу      |
|               |                   |
|               V                   |
|   Добавление в список растений    |
|   пользователя                    |
|               |                   |
|               V                   |
|   Определение растений, которые   |
|   нужно полить сегодня            |
|               |                   |
|               V                   |
|   Отображение на сайте            |

# Технологии

## Frontend

HTML, CSS, Bootstrap, Jinja2, Vanilla JS

## Backend

1. Взаимодействие с БД
sqlalchemy, sqlite

2. Настройки
Pydantic, python-dotenv

3. Сайт
Flask, werkzeug

4. API
Plant.id API
