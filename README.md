# Happy Plant - трекер полива растений

Вебсайт, который определяет растения по фото, отслеживает время их полива. 

# Как работает

|   Пользователь загружает фото     |\n
|               |                   |\n
|               V                   |\n
|   Обращение к Plant.id API за     |\n
|   инфомацией о виде растения      |\n
|   и рекомендациями по поливу      |\n
|               |                   |\n
|               V                   |\n
|   Добавление в список растений    |\n
|   пользователя                    |\n
|               |                   |\n
|               V                   |\n
|   Определение растений, которые   |\n
|   нужно полить сегодня            |\n
|               |                   |\n
|               V                   |\n
|   Отображение на сайте            |\n

# Технологии

## Frontend

HTML, CSS, Bootstrap, Jinja2, Vanilla JS

## Backend

1. Взаимодействие с БД
sqlalchemy, sqlite

2. Настройки
Pydantic, python-dotenv

3. Сайт
Flask, werkzeug

4. API
Plant.id API
